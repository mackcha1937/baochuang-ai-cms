## 4. 反向路径

- 非当前版本、未确认产品、历史版本和重复建版均有稳定的错误或幂等返回；已确认版本不可直接修改/删除。
- V2 缺新资料、缺生效时间、关键字段未全部人工确认时禁止确认；修改事实会自动撤销该项确认。
- 素材处置缺原因时页面和 API 均拒绝；非法状态、不允许的跳转、非批准素材下载和不存在对象均被拒绝。
- `viewer-demo` 尝试创建新产品版本返回 403，同时记录权限拒绝审计。
- Stage 02 已有 PDF/DOCX/XLSX 扩展名、MIME、签名、大小、文件名和路径反向用例全量回归通过。

## 5. 取消、异常恢复与冲突

- 创建新版本前有人工确认；取消不产生草稿。V2 草稿可删除，返回产品列表；已确认版本不可删除。
- 修订号对字段保存和素材草稿创建进行并发保护，重复请求不创建多份 V2。
- 可能过期素材可关联当前 V2 创建独立修订草稿；旧批准快照不可变。
- 失效恢复只到待复核，复核人必须再记录原因才能恢复批准，不存在绕过复核的直接状态切换。

## 6. 权限、安全与审计

- 产品新建/更新/确认复用 `product.create`、`product.update`、`product.confirm`；素材查看、修订、失效与下载分别受现有权限门禁保护。
- V2 确认、旧素材可能过期、保持有效、修订、失效和恢复均记录操作人、对象、原因和时间；服务重启后审计页可完整查询。
- 失效、可能过期、待复核素材保持只读且不显示下载，服务端同时拒绝绕过 UI 的下载。
- 文件上传安全、随机存储键、路径隔离和失败残片清理完整回归；跟踪文件中未发现 API Key。
