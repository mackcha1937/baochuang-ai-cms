## 4. 反向路径、取消与返回

- 新建弹窗“取消”和遮罩关闭均不创建空草稿；详情返回时有未保存修改确认。
- 重名产品返回 409 并要求二次确认；相同幂等键不重复创建。
- TXT/Markdown 扩展名、错误 MIME、伪造 PDF、空文件及超过 20 MB 文件均由服务端拒绝，磁盘不留残片。
- 浏览器上传伪造 PDF 显示“文件内容不是有效 PDF”，资料数保持 0。
- 上传请求支持前端中止；已入库任务支持取消；取消状态可重试或删除。
- 删除文件同时删除解析记录和随机存储对象；删除未确认草稿同时清理所属文件；已确认产品不可删除或直接覆盖。

## 5. 异常恢复与失败重试

- 空白/扫描 PDF 进入 `needs_manual`，可粘贴原文转为 `manual_ready` 并作为确认来源。
- `failed`、`needs_manual`、`cancelled` 状态可重试；尝试次数、状态和审计均更新。
- 网络/接口错误使用统一可恢复提示；产品列表、详情和审计页保留重试入口。
- 修订号不匹配返回 `REVISION_CONFLICT`，防止并发页面静默覆盖。
- 解析异常返回公开错误文案，不向响应泄露堆栈、存储绝对路径或内部异常。

## 6. 权限与安全

- 写接口分别校验 `product.create`、`product.update`、`product.confirm`；审计查询校验 `audit.view`。
- 只读演示用户调用创建接口返回 403，未知演示用户返回 401；越权尝试写入 `permission.denied` 审计且不改变业务数据。
- 允许扩展名仅 `.pdf/.docx/.xlsx`；同时校验 MIME 和文件签名/ZIP 内部结构。
- 文件按 1 MB 分块读取，服务端强制 20 MB 上限；超限与校验失败后删除临时文件。
- 展示文件名进行 Unicode 规范化、路径剥离、控制字符清理和长度限制；磁盘文件名为随机 storage key。
- 存储路径解析后必须位于配置的上传根目录；API 不返回本机绝对路径和 storage key。
- 被拒绝上传写入 `document.upload.rejected`，审计只含安全展示名与错误码，不含本机路径或文件内容。
- `.env`、数据库、上传目录、工作文件和真实 API Key 均不进入 Git。
