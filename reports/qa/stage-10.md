## 4. 反向路径

- `viewer-demo` 读取权限矩阵和审计列表均返回 403/`PERMISSION_DENIED`；拒绝分别追加 `user.manage`、`audit.view` 审计。
- 非法时间返回 422/`AUDIT_TIME_INVALID`，开始晚于结束返回 422/`AUDIT_TIME_RANGE_INVALID`；不同 UTC 偏移按实际时刻而非字符串顺序判断。
- `limit=201`、`offset=10001` 返回 422；不存在审计详情返回 404/`AUDIT_LOG_NOT_FOUND`。
- 权限资源的 POST/PATCH/DELETE 及审计详情的 POST/PATCH/DELETE 均为 404/405；真实生产烟测 DELETE 审计返回 405。
- 自动化在写接口探测前后比较记录数量与内容，数据不变；直接 SQLite UPDATE/DELETE 同样由触发器拒绝。

## 5. 取消、返回与异常恢复

- 详情关闭不改变筛选条件；筛选空状态和表单均提供重置路径，恢复后重新读取服务端完整列表。
- 权限和审计初次加载失败显示错误及“重新加载”；前端自动化覆盖 403 后重试成功。
- 查询中按钮禁用并显示“查询中…”，已有结果时后续详情错误保留当前列表，不清空可用数据。
- 第一次停止/重启开发服务后，同一浏览器空间重新加载权限与审计页面，未出现致命错误或丢失状态。

## 6. 权限、安全与审计

- 权限矩阵需要 `user.manage`，审计列表/详情需要 `audit.view`；固定只读访客没有任何有效权限。
- 权限角色映射和说明由服务端单一契约输出，前端不自行推断；用户列表来自持久化数据库。
- 审计查询只允许固定列集合，文本条件长度受限，时间格式/范围、limit 和 offset 均有边界并使用绑定参数。
- 审计只有服务端内部追加方法；外部 API 无写路由，数据库 `audit_logs_no_update`、`audit_logs_no_delete` 触发器阻止直接篡改。
- `.env`、SQLite、上传与生成文件保持 Git 忽略；跟踪文件密钥模式扫描无结果，业务代码无本机绝对路径。
- `permission.denied` 记录包含操作者、缺失权限码和拒绝摘要；重启后仍可按操作者/动作/对象查询。
