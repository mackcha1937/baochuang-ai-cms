## 启动与复测

```bash
npm run check
npm run demo
```

默认访问 `http://127.0.0.1:8765`。上传目录可通过 `APP_UPLOAD_DIR` 替换，单文件上限可通过 `APP_MAX_UPLOAD_BYTES` 调整，默认 20 MB；数据库继续通过 `APP_DATABASE_URL` 配置。

## 密钥与门禁

- 用户配置的真实 DeepSeek Key 仅由服务端从本机 `.env` 读取用于联调；Key 未写入代码、前端、响应、日志、数据库、报告或 Git。`.env`、运行数据库和上传文件继续被 Git 忽略。
